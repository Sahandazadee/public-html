3. Most-used commands (Arduino-ESP32 core 3)

pinMode(pin, OUTPUT);            // INPUT, INPUT_PULLUP, INPUT_PULLDOWN
digitalWrite(pin, HIGH);         // HIGH = 3.3V, LOW = 0V
int b = digitalRead(pin);        // 0 or 1
int a = analogRead(pin);         // 0..4095
int mv = analogReadMilliVolts(pin);
ledcAttach(pin, 5000, 8);        // PWM: frequency and resolution bits
ledcWrite(pin, 128);             // 0..255 at 8 bits
unsigned long t = millis();      // ms since power-up
Serial.begin(115200);  Serial.println(x);
Wire.begin(21, 22);              // I2C
WiFi.begin(ssid, pass);  WiFi.status() == WL_CONNECTED;
esp_sleep_enable_timer_wakeup(10ULL * 1000000);  esp_deep_sleep_start();
  1. Digital. Set a pin's role, write and read ones and zeros. The most basic thing you do with any GPIO; lessons 2.2, 2.3 and 3.1.
  2. Analog. The raw ADC number, or the voltage in millivolts. The millivolt version is calibrated and easier for a beginner to understand; lesson 3.1.
  3. PWM in core 3. In core 2 this was ledcSetup and ledcAttachPin. Older tutorials online are written for core 2 and don't compile on core 3; lesson 3.2.
  4. Timing without stopping. The replacement for delay when you need to do several things at once; lesson 3.1.
  5. Communication. Serial, I2C and Wi-Fi. Lessons 2.2, 3.3 and 4.1.
  6. A 10-second deep sleep. The time is in microseconds and must be a 64-bit number (ULL). Without ULL the big number overflows; lesson 6.1.

4. Formulas

FormulaExample
Ohm's law: V = I × RLED resistor: (3.3 − 2.0) ÷ 0.006 ≈ 220Ω
Voltage divider: Vout = Vin × R2 ÷ (R1 + R2)3.3 × 10k ÷ 20k = 1.65V
Voltage from the ADC: V ≈ raw × 3.3 ÷ 40952048 → about 1.65V (approximate; better: analogReadMilliVolts)
Battery life: hours = mAh ÷ average current (mA)2000 ÷ 0.5mA = 4000 hours (less in practice)
PWM: duty = fraction × (2^bits − 1)50% at 8 bits: 0.5 × 255 ≈ 128
