۳. دستورهای پرکاربرد (Arduino-ESP32 نسخه 3)

pinMode(pin, OUTPUT);            // INPUT, INPUT_PULLUP, INPUT_PULLDOWN
digitalWrite(pin, HIGH);         // HIGH = 3.3V, LOW = 0V
int b = digitalRead(pin);        // 0 یا 1
int a = analogRead(pin);         // 0..4095
int mv = analogReadMilliVolts(pin);
ledcAttach(pin, 5000, 8);        // PWM: فرکانس و تعداد بیت
ledcWrite(pin, 128);             // 0..255 در 8 بیت
unsigned long t = millis();      // زمان از روشن شدن
Serial.begin(115200);  Serial.println(x);
Wire.begin(21, 22);              // I2C
WiFi.begin(ssid, pass);  WiFi.status() == WL_CONNECTED;
esp_sleep_enable_timer_wakeup(10ULL * 1000000);  esp_deep_sleep_start();
  1. دیجیتال. تعیین نقش پایه، نوشتن و خواندن صفر و یک. پایه‌ترین کار با هر GPIO؛ درس ۲.۳ و ۳.۱.
  2. آنالوگ. عدد خام ADC یا ولتاژ بر حسب میلی‌ولت. نسخه میلی‌ولتی کالیبره است و برای مبتدی قابل فهم‌تر است؛ درس ۳.۱.
  3. PWM در نسخه ۳. در نسخه ۲ جای آن ledcSetup و ledcAttachPin بود. آموزش‌های قدیمی اینترنت با نسخه ۲ هستند و در نسخه ۳ کامپایل نمی‌شوند؛ درس ۳.۲.
  4. زمان بدون توقف. جایگزین delay برای انجام چند کار با هم؛ درس ۳.۱.
  5. ارتباط‌ها. سریال، I2C و Wi-Fi. درس‌های ۲.۳، ۳.۳ و ۴.۱.
  6. خواب عمیق ۱۰ ثانیه‌ای. زمان بر حسب میکروثانیه و از نوع ۶۴ بیتی (ULL). بدون ULL عدد بزرگ سرریز می‌کند؛ درس ۶.۱.

۴. فرمول‌ها

فرمولمثال
قانون اهم: V = I × Rمقاومت LED: (3.3 − 2.0) ÷ 0.006 ≈ 220Ω
تقسیم ولتاژ: Vout = Vin × R2 ÷ (R1 + R2)3.3 × 10k ÷ 20k = 1.65V
ولتاژ از ADC: V ≈ raw × 3.3 ÷ 40952048 → حدود 1.65V (تقریبی؛ بهتر: analogReadMilliVolts)
عمر باتری: ساعت = mAh ÷ میانگین جریان2000 ÷ 0.5mA = 4000 ساعت (در عمل کمتر)
PWM: duty = درصد × (2^بیت − 1)۵۰٪ در ۸ بیت: 0.5 × 255 ≈ 128
