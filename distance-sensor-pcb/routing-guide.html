کلیدهای میانبر — حفظ کن
چرا: بدون کلیدهای میانبر، routing خیلی کند می شه. این کلیدها از مستندات رسمی KiCad 10 هستند.
  • X
    شروع route — روی pad کلیک کن یا کلید X
    cursor تبدیل می شه به حالت routing
  • W
    تغییر عرض trace — کلید W حین routing
    بین 0.2mm و 0.3mm سوئیچ می کنه
  • /
    تغییر جهت خم — کلید / بین H→V و V→H
    وقتی می خوای اول عمودی بری بعد افقی
  • 6
    Differential Pair — کلید 6 برای USB_DP/DM
    هر دو trace رو همزمان می کشه
  • V
    Via — کلید V حین routing — لایه رو عوض می کنه
    F.Cu به B.Cu یا برعکس
  • U
    Select connected — کلید U
    همه traces یه net رو انتخاب می کنه — برای حذف route اشتباه
  • N
    تغییر Grid — کلید N
    Grid 0.25mm برای routing — traces باید روی grid باشند (PCB Runner)
  • Esc
    لغو — Escape — trace ناقص حذف می شه
💡 KiCad 10: بعد از کشیدن trace، right-click کن و "Fillet" رو انتخاب کن تا گوشه 90° به 45° تبدیل شه. Radius پیشنهادی: 0.5mm.

۶
USB Differential Pair — USB_DP و USB_DM
چرا (DigiKey): USB 2.0 از سیگنال differential استفاده می کند. D+ و D- باید موازی، هم طول، و در کنار هم باشند — وگرنه USB unreliable می شود.
💡 USB 2.0 نیاز به differential impedance 90Ω دارد. برای FR4 با 1.6mm: trace width ≈ 0.2mm، spacing ≈ 0.2mm
  • 6
    منو Route → Route Differential Pair یا کلید 6
    cursor تبدیل می شه به دو خط موازی
  • A6
    روی pad A6 یا B6 کانکتور J1 کلیک کن (USB_DP)
    KiCad خودش جفت D- رو پیدا می کنه
  • ↔
    هر دو trace را به CH340C وصل کن — DP به پین DP، DM به پین DM
    فاصله بین دو trace ≈ 0.2mm حفظ می شه
Differential Pair — USB_DP / USB_DM
⚠️ اگه USB_DP/DM موازی و هم طول نباشند، USB unreliable یا کار نمی کنه.

GND Copper Pour
چرا (Sierra Circuits): به جای 41 trace جداگانه، یک copper pour کل F.Cu رو پر می کنه. نتیجه: impedance کمتر، heat dissipation بهتر، EMI کمتر.

    بعد از OK، دور کل board رسم کن — 4 گوشه edge، double-click برای بستن
  • KO
    Keepout زیر آنتن ESP8266: Place → Add Rule Area
    Layer: F.Cu — تیک "Copper Fill: Prohibited" — زیر آنتن (~5×3mm)
  • B
    Fill کردن: کلید B یا Edit → Fill All Zones
  • 🔩
    Ground stitching vias (Sierra Circuits): چند via GND در لبه های board
    copper pour دو طرف به هم وصل می شند = EMI بهتر
💡 Clearance 0.5mm عمداً بیشتر از minimum است — فاصله بیشتر از صفحه GND = capacitive coupling کمتر.
