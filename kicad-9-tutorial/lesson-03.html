رسمِ شماتیک (Schematic Capture)Schematic Capture

حالا همه‌ی قطعات را کنارِ هم می‌چینیم و با سیم به‌هم وصل می‌کنیم تا «نقشه‌ی مدار» کامل شود.Now we place all parts and wire them together to complete the circuit diagram.

بلوکِ عنوان و نسخه‌گذاریTitle block & versioning

از File → Page Settings، بلوکِ پایینِ صفحه را پر کن: تاریخ، عنوان (555 Badge)، نسخه (v01).

Via File → Page Settings, fill the title block: date, title (555 Badge), revision (v01).

قراردادنِ قطعاتPlacing components

با ابزارِ Place Symbol (کلیدِ میان‌بر A) قطعات را اضافه کن.

Use Place Symbol (shortcut A) to add parts.

افزودنِ کتابخانه‌ی DigiKeyAdding the DigiKey library

جالباتری (BS-7) و کلیدِ کشویی (EG1218) در کتابخانه‌ی KiCad متعلق به DigiKey روی GitHub هستند.

The battery holder (BS-7) and slide switch (EG1218) are in DigiKey's KiCad library on GitHub.

پرچم‌های تغذیه و زمین، و سیم‌کشیPower/ground flags & wiring

از پرچم (power flag) برای تغذیه و زمین استفاده کن. با ابزارِ Wire (کلیدِ W) بقیه‌ی اتصالات را بکش.

Use power flags for power and ground. Use the Wire tool (W) to draw connections.
