# آموزش KiCad 9 برای مبتدیان — وب‌سایت

این پوشه (`kicad-9-tutorial/`) شاملِ یک وب‌سایتِ آموزشیِ کاملِ **استاتیک** برای یادگیریِ طراحیِ PCB و Schematic با **KiCad 9** است. محتوا بر پایه‌ی سری ویدیوهای *«An Intro to KiCad»* از کانال **DigiKey** (شاون هایمل) ساخته شده و با معادل‌های **KiCad 9** و قوانینِ تولیدِ **JLCPCB** کامل شده است.

## 🌐 لینکِ سایت

**https://sahandazadee.github.io/public-html/kicad-9-tutorial/**

## ویژگی‌ها

- 🇮🇷 کاملاً **فارسی (راست‌چین)** با دکمه‌ی تغییر زبان به **انگلیسی** در بالای صفحه
- 🌗 حالتِ روشن/تاریک
- 📺 ویدیوی رسمیِ DigiKey در هر درس
- 🧩 ۱۰ درس دقیقاً به‌ترتیبِ ویدیوها + یک درسِ مرجعِ **قوانینِ JLCPCB**
- ✏️ تصویرسازی‌های SVG و توضیحِ **«چرا»** برای هر تصمیمِ طراحی

## ساختار

| فایل | محتوا |
|------|--------|
| `index.html` | شروع، نقشه‌ی راه، نصبِ KiCad 9 |
| `lesson-01..10.html` | ده درس متناظر با ده ویدیوی DigiKey |
| `lesson-11.html` | مرجعِ قوانینِ طراحیِ JLCPCB |
| `assets/style.css`, `assets/app.js` | استایل و منطقِ تغییر زبان/تم |
