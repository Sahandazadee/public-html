تولیدِ Gerber و سفارشِ بردGenerating Gerbers & Ordering

برد آماده است. حالا باید آن را به زبانی که کارخانه می‌فهمد تبدیل کنیم: فایل‌های Gerber و فایلِ سوراخ‌کاری.The board is done. Now we translate it into the language fabs understand: Gerber files plus a drill file.

Gerber چیست؟What is a Gerber?

برای هر لایه‌ی برد یک فایلِ Gerber جدا تولید می‌شود: مسِ بالا، مسِ پایین، سولدرماسک، سیلک و...

One Gerber file per board layer: top copper, bottom copper, soldermask, silkscreen, etc.

خروجی‌گرفتنِ لایه‌ها (Plot)Plotting the layers

از File → Plot، یک پوشه‌ی Gerbers بساز و لایه‌های مسِ جلو/عقب، سیلکِ جلو/عقب، ماسکِ جلو/عقب، و Edge.Cuts را انتخاب کن. سپس Generate Drill File را بزن.

From File → Plot, make a Gerbers folder and select: front/back copper, silkscreen, mask, and Edge.Cuts. Then click Generate Drill File.

در KiCad 9In KiCad 9

در KiCad 9 می‌توانی از File → Fabrication Outputs هم استفاده کنی. مهم این است که همه‌ی لایه‌ها + drill را در یک ZIP بگذاری.

In KiCad 9 you can also use File → Fabrication Outputs. The key is putting all layers + drill into one ZIP.

بررسیِ Gerberها با GerbviewChecking Gerbers in Gerbview

قبل از سفارش، Gerberها را در Gerbview ببین. اول فایلِ drill و Edge.Cuts را بارگذاری کن؛ اگر سوراخی بیرونِ لبه‌ی برد بود، یعنی اشتباه شده.

Before ordering, view Gerbers in Gerbview. Load drill and Edge.Cuts first; if any hole sits outside the outline, something went wrong.

بسته‌بندی و سفارشZip & order

پوشه‌ی Gerbers را در یک .zip فشرده کن. در JLCPCB روی «Add gerber file» بزن، ZIP را بالا بده، تعداد و گزینه‌ها را انتخاب کن و سفارش بده.

Compress the Gerbers folder into a .zip. On JLCPCB click "Add gerber file", upload the ZIP, choose quantity and options, and order.
