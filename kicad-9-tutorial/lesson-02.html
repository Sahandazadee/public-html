ساختِ یک سمبلِ شماتیکCreating a Schematic Symbol

هر قطعه در شماتیک با یک «سمبل» نشان داده می‌شود. اینجا سمبلِ تایمر ۷۵۵۵ را از صفر، با کمکِ دیتاشیت می‌سازیم.Every part in a schematic is drawn as a "symbol". Here we build the 7555 timer's symbol from scratch using its datasheet.

  • سمبل را در کتابخانه‌ی اختصاصیِ پروژه ذخیره کن.
  • پین‌ها: تغذیه بالا، زمین پایین، خروجی سمتِ راست.
  • تیلدا (~) = active-low.
  • Origin در مرکزِ سمبل.
  • Save the symbol in a project-specific library.
  • Pins: power on top, GND at bottom, output on the right.
  • Leading tilde (~) = active-low.
  • Keep origin point centered in the symbol.

ساختِ پروژه و بازکردنِ ویرایشگرِ سمبلCreate the project & open the Symbol Editor

  1. در Project Manager: File → New Project. یک پوشه‌ی مرتب بساز (مثلاً Documents/KiCad/555_Badge) و پروژه را 555_Badge نام بده.
  2. ابزارِ Symbol Editor را باز کن (در ویدیوی قدیمی: «Library Editor»).
  3. یک کتابخانه‌ی جدیدِ مخصوصِ پروژه بساز و سمبلِ جدید را با نام 7555 و RefDes حرفِ U ایجاد کن.
  1. In the Project Manager: File → New Project. Make a tidy folder (e.g. Documents/KiCad/555_Badge) and name the project 555_Badge.
  2. Open the Symbol Editor (old video: "Library Editor").
  3. Create a new project-specific library and a new symbol named 7555 with reference designator letter U.
چرا این کار را می‌کنیم؟Why we do this

چرا کتابخانه‌ی «مخصوصِ پروژه»؟ چون قطعاتِ سفارشی همراهِ خودِ پروژه جابه‌جا می‌شوند؛ اگر پروژه را روی GitHub بگذاری یا برای کسی بفرستی، سمبل‌هایت گم نمی‌شوند. قطعاتِ عمومی و پرکاربرد را می‌توان در کتابخانه‌ی سراسری (global) نگه داشت.

Why a "project-specific" library? Custom parts travel with the project; if you upload to GitHub or share it, your symbols won't be lost. Generic, reusable parts can live in a global library instead.

نکتهTip

RefDes یعنی Reference Designator: یک حرف که نوعِ قطعه را می‌گوید. R مقاومت، C خازن، U مدارِ مجتمع (IC)، D دیود، Q ترانزیستور. تایمرِ ما یک IC است، پس U.

RefDes = Reference Designator: a letter telling the part type. R resistor, C capacitor, U integrated circuit, D diode, Q transistor. Our timer is an IC, so U.

افزودنِ پین‌ها از روی دیتاشیتAdding pins from the datasheet

دیتاشیتِ بسته‌ی DIP ۸ پایه می‌گوید هر پین چه نام و چه شماره‌ای دارد. نام کارِ پین را توصیف می‌کند و شماره می‌گوید آن پین کجای قطعه‌ی فیزیکی است. این دو باید دقیقاً با دیتاشیت بخوانند.

The 8-pin DIP datasheet tells each pin's name and number. The name describes the pin's function; the number tells where the pin physically sits. These two must match the datasheet exactly.

پین‌ها را با نام‌های GND(1), ~TRIG(2), OUT(3), ~RST(4), CV(5), THR(6), DIS(7), VDD(8) اضافه کن.

Add pins named GND(1), ~TRIG(2), OUT(3), ~RST(4), CV(5), THR(6), DIS(7), VDD(8).

چرا این کار را می‌کنیم؟Why we do this

کاراکترِ تیلدا (~) قبل از نام، یک خطِ افقی روی نام می‌کشد؛ یعنی پین active-low است (با سطحِ پایین فعال می‌شود). نگه‌داشتنِ این خط در سمبل کمک می‌کند هنگامِ خواندنِ شماتیک، رفتارِ پین را فوری بفهمی.

A leading tilde (~) draws a bar over the name, meaning the pin is active-low (asserted when low). Keeping that bar helps you instantly read the pin's behaviour on the schematic.

چیدمانِ پین‌ها برای خواناییArranging pins for readability

نکته‌ی مهم: پین‌ها را به ترتیبِ شماره نچین. در عوض، طوری بچین که خواندنِ مدار آسان شود — معمولاً تغذیه بالا، زمین پایین، خروجی سمتِ راست و بقیه سمتِ چپ. سپس یک مستطیل دورِ پین‌ها بکش تا تمیز شود.

Important: don't arrange pins by number. Instead, arrange for reading the circuit — usually power on top, ground at bottom, output on the right, and the rest on the left. Then draw a rectangle around the pins to tidy it up.

چرا این کار را می‌کنیم؟Why we do this

سمبل لازم نیست شبیهِ ظاهرِ فیزیکیِ قطعه باشد؛ فقط باید اتصالات را خوانا کند. چیدمانِ منطقی، خطاهای سیم‌کشی را کم می‌کند و نقشه‌ی شما را برای دیگران (و خودِ آینده‌ات) قابل‌فهم نگه می‌دارد.

A symbol need not look like the physical part; it just needs to make connections readable. A logical layout reduces wiring mistakes and keeps your schematic understandable for others (and future-you).

نکتهTip

نقطه‌ی origin (تقاطعِ دو خطِ آبی) جایی است که هنگام قراردادن، قطعه به نشانگرِ ماوس می‌چسبد و حول آن می‌چرخد. آن را در مرکزِ سمبل نگه‌دار تا جابه‌جایی و چرخش راحت باشد.

The origin (where the two blue lines cross) is where the part attaches to your cursor and rotates around when placing. Keep it centered for easy moving and rotating.

در KiCad 9In KiCad 9

در KiCad 9 برخی منوها جابه‌جا شده‌اند، اما مفهومِ «کتابخانه‌ی کاری»، افزودنِ پین، و کشیدنِ مستطیل دقیقاً همان است. ذخیره: File → Save.

In KiCad 9 some menus moved, but the concepts of a working library, adding pins, and drawing a rectangle are identical. Save with File → Save.
