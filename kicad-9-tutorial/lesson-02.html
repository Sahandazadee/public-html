ساختِ یک سمبلِ شماتیکCreating a Schematic Symbol

هر قطعه در شماتیک با یک «سمبل» نشان داده می‌شود. اینجا سمبلِ تایمر ۷۵۵۵ را از صفر، با کمکِ دیتاشیت می‌سازیم.Every part in a schematic is drawn as a "symbol". Here we build the 7555 timer's symbol from scratch using its datasheet.

ساختِ پروژه و بازکردنِ ویرایشگرِ سمبلCreate the project & open the Symbol Editor

  1. در Project Manager: File → New Project. پروژه را 555_Badge نام بده.
  2. ابزارِ Symbol Editor را باز کن.
  3. یک کتابخانه‌ی جدیدِ مخصوصِ پروژه بساز و سمبلِ جدید را با نام 7555 و RefDes حرفِ U ایجاد کن.
  1. In the Project Manager: File → New Project. Name it 555_Badge.
  2. Open the Symbol Editor.
  3. Create a new project-specific library and a new symbol named 7555 with RefDes letter U.

افزودنِ پین‌ها از روی دیتاشیتAdding pins from the datasheet

پین‌ها را با نام‌های GND(1), ~TRIG(2), OUT(3), ~RST(4), CV(5), THR(6), DIS(7), VDD(8) اضافه کن.

Add pins named GND(1), ~TRIG(2), OUT(3), ~RST(4), CV(5), THR(6), DIS(7), VDD(8).

چیدمانِ پین‌ها برای خواناییArranging pins for readability

پین‌ها را به ترتیبِ شماره نچین — طوری بچین که خواندنِ مدار آسان شود: تغذیه بالا، زمین پایین، خروجی سمتِ راست.

Don't arrange pins by number. Arrange for reading the circuit: power on top, ground at bottom, output on the right.
