# PRD — اپ دفترچه تلفن ایزوله (PhoneBook Vault)

## ۱. هدف
یک اپ **اندروید واقعی (APK)**، **کاملاً آفلاین** و امن برای نگه‌داری مخاطبین و متن‌ها. هیچ دسترسی به اینترنت ندارد (مجوز `INTERNET` در اندروید حذف شده؛ یعنی حتی اگر کسی بخواهد، اپ نمی‌تواند داده‌ای بفرستد).

## ۲. اصول
- زبان رابط: انگلیسی. ذخیره/جستجوی متن و شمارهٔ فارسی (و ارقام فارسی/عربی) کاملاً پشتیبانی می‌شود.
- هیچ سرویس ابری، تبلیغ، آنالیتیکس، یا فونت/کتابخانهٔ آنلاین ندارد.
- پشتیبان خودکار در حافظهٔ اصلی گوشی (پوشهٔ `Documents/PhoneBook`) که **با پاک‌کردن اپ پاک نمی‌شود**.
- Auto-Backup گوگل خاموش است (`allowBackup=false`) تا داده به ابر نرود.

## ۳. کاربر هدف
یک نفر که می‌خواهد مخاطبینش را روی گوشی، خصوصی و منظم نگه دارد و هر وقت خواست روی کامپیوتر منتقل کند.

## ۴. قابلیت‌ها (Scope)
### الف) مخاطبین (مثل دفترچهٔ گوشی)
- فیلدها: نام، نام‌خانوادگی، شرکت، سمت، **چند شماره** (با برچسب Mobile/Home/Work/…)، **چند ایمیل**، **چند آدرس**، وب‌سایت، تاریخ تولد، یادداشت، دستهٔ مخاطب، پوشه، ستاره‌دار.
- آواتار رنگی با حروف اول نام (فارسی و انگلیسی).
- لیست الفبایی با سرتیتر حروف و نوار حروف کنار صفحه.
- صفحهٔ جزئیات با دکمه‌های **Call / SMS / Email / Map / Share**.
- لمس شماره = باز شدن شماره‌گیر؛ نگه‌داشتن = کپی.

### ب) ورودی متنی (Notes)
- علاوه بر مخاطب، «متن آزاد» (آدرس، رمز، یادداشت…) با عنوان، متن، دسته و پوشه.

### ج) دسته‌بندی و پوشه
- دسته‌ها (Categories): Phones, Addresses, Work, Family, Friends, Emergency, Other + ساخت/ویرایش/حذف دستهٔ دلخواه با رنگ.
- پوشه‌ها (Folders): ساخت/تغییر نام/رنگ/آیکون/حذف؛ داخل هر پوشه یک یا چند مخاطب/متن. جابه‌جایی بین پوشه‌ها.

### د) جستجو، فیلتر، مرتب‌سازی
- دکمهٔ Search همیشه بالای صفحه؛ جستجو در همهٔ فیلدها؛ بدون حساسیت به حروف؛ ارقام ۰۱۲/٠١٢/012 یکسان؛ «ي/ك» عربی = «ی/ک» فارسی.
- فیلتر: دسته، پوشه، ستاره‌دار، دارای شماره/ایمیل/آدرس.
- مرتب‌سازی: نام A→Z / Z→A، جدیدترین اضافه، آخرین ویرایش.
- سه حالت نمایش: **List**، **Cards**، **Table** (جدول: Name | Phone | Email | Address | Category | Folder؛ ستون اول چسبیده؛ اسکرول افقی).

### ه) امنیت
- قفل **PIN** (۴ تا ۶ رقم، ذخیره به‌صورت hash+salt) + **اثرانگشت/بیومتریک** (BiometricPrompt اندروید).
- قفل خودکار هنگام رفتن به پس‌زمینه؛ ۵ بار PIN غلط = تأخیر.
- پنجرهٔ اپ در لیست Recent و اسکرین‌شات مخفی (`FLAG_SECURE`).

### و) پشتیبان‌گیری و انتقال (آفلاین)
- **Backup خودکار** پس از هر تغییر (حداکثر یک فایل در روز) → `Documents/PhoneBook/` در حافظهٔ اصلی.
- **Backup دستی** با فرمت: **JSON** (کامل، قابل Restore)، **TXT** (قابل‌خواندن)، **CSV** (اکسل)، **VCF** (وارد کردن به دفترچهٔ گوشی)، **PDF** (چاپی)، **JPG** (تصویر).
- **Restore** از فایل JSON با انتخاب فایل (Merge یا Replace) و پیش‌نمایش تعداد.
- ذخیره‌ها در Documents/PhoneBook ← با USB یا File Manager روی کامپیوتر کپی می‌شود.

### ز) اشتراک‌گذاری
- Share یک مخاطب/چند مخاطب انتخاب‌شده/یک پوشه به‌صورت **متن** یا فایل **VCF** با Share Sheet اندروید.

### ح) قابلیت‌های تکمیلی
- **Trash** (سطل زباله): حذف = انتقال به سطل؛ Restore یا Delete forever؛ پاکسازی خودکار بعد از ۳۰ روز.
- **Favorites** در صفحهٔ جدا.
- تشخیص **مخاطب تکراری** (شماره یکسان) + ادغام.
- انتخاب چندتایی (Multi-select): حذف، جابه‌جایی به پوشه، تغییر دسته، Share.
- **Import** از VCF و CSV (انتقال از دفترچهٔ فعلی گوشی: Contacts → Export → VCF).
- تم **Dark / Light / Auto** و ۶ رنگ تاکیدی (Accent).
- آمار: تعداد مخاطبین/پوشه‌ها/دسته‌ها.
- تغییر PIN، خاموش/روشن بیومتریک، پاک‌کردن کامل داده.

## ۵. خارج از محدوده (عمداً)
همگام‌سازی ابری، اتصال به اینترنت، دسترسی به مخاطبین سیستم (مجوز `READ_CONTACTS` نمی‌گیریم تا حریم کامل بماند؛ انتقال با VCF).

## ۶. معماری فنی
| بخش | انتخاب | دلیل |
|---|---|---|
| پوسته | **Capacitor 8** (APK واقعی) | UI زیبا با HTML/CSS؛ فارسی/RTL عالی؛ بدون INTERNET |
| UI | HTML + CSS + JavaScript خالص | بدون وابستگی، کاملاً آفلاین، قابل تست در مرورگر |
| ذخیره | IndexedDB-free: `localStorage` JSON + پشتیبان فایل | ساده و مطمئن برای ده‌ها هزار مخاطب |
| Native | پلاگین جاوا `NativeBridge` | MediaStore (ذخیره در Documents)، BiometricPrompt، FLAG_SECURE |
| PDF/JPG | Canvas در WebView (شکل‌دهی درست متن فارسی) → JPEG → PDF دست‌ساز | بدون کتابخانه |
| ساخت APK | GitHub Actions (JDK 21 + Android SDK) | محیط ابری فعلی به Google Maven دسترسی ندارد |
| امضا | کلید ثابت `phonebook.keystore` | به‌روزرسانی روی نسخهٔ قبلی بدون پاک‌شدن داده |

### ذخیره در حافظهٔ اصلی بدون پاک‌شدن با Uninstall
Android 10+ (Scoped Storage): با `MediaStore.Files` در `Documents/PhoneBook` فایل می‌سازیم؛ فایل‌های Documents با حذف اپ پاک نمی‌شوند. Android 9 و پایین‌تر: مجوز `WRITE_EXTERNAL_STORAGE` (فقط تا API 28).

### مدل داده
```
Entry { id, type:'contact'|'note', first,last,company,title,
        phones[{label,value}], emails[{label,value}], addresses[{label,value}],
        website, birthday, notes, text(for note), title(for note),
        categoryId, folderId, fav, created, updated, deletedAt|null }
Folder { id, name, color, icon }   Category { id, name, color }
Settings { theme, accent, view, sort, pinHash, pinSalt, bio, autoBackup }
```

## ۷. معیارهای پذیرش
1. APK نصب می‌شود و `INTERNET` در Manifest نیست (قابل‌بررسی با `aapt dump permissions`).
2. افزودن مخاطب با نام فارسی و شمارهٔ فارسی؛ جستجوی «0912» و «۰۹۱۲» هر دو پیدایش می‌کنند.
3. پوشه بساز، چند مورد داخلش بریز، جابه‌جا کن.
4. هر ۶ فرمت خروجی ساخته و در `Documents/PhoneBook` دیده می‌شود.
5. حذف اپ ← نصب دوباره ← Restore از فایل JSON ← همه‌چیز برمی‌گردد.
6. بدون PIN نمی‌شود وارد شد؛ اثرانگشت کار می‌کند.
7. تست خودکار مرورگر (Playwright) روی جریان‌های اصلی سبز است.
