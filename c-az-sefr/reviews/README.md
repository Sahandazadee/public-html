# ریویوی شاگردان مجازی

هر دور ۵ ایجنت با پروفایل‌های PRD بند ۱۰ بخش‌هایی از دوره را می‌خوانند و گزارش می‌دهند. گزارش‌ها در `r<دور>-<پروفایل>.md`؛ خلاصه و اقدام‌ها در `../REVIEW-LOG.md`.
قالب هر گزارش: ۱) جایی که گیج شدم (درس، بخش، چرا) ۲) اصطلاحی که بدون تعریف آمد ۳) کدی که کار نکرد یا خروجی‌اش فرق داشت (فایل، دستور، خروجی واقعی) ۴) مطلبی که کم است ۵) باگ صفحه/ظاهر ۶) شدت هر مورد: حاد / متوسط / جزئی.
