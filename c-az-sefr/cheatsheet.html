صفحه همراه

برگه خلاصه قابل چاپ

همه‌چیزهایی که هر بار می‌خواهی یادت بیاید، روی یک صفحه: نوع‌ها، اولویت عملگرها، ترفندهای بیت، اشاره‌گر، printf، قواعد volatile و const، دستور کار با رجیستر و هشدارهای رایج. توجه: این صفحه یادآور است، نه جایگزین درس‌ها؛ هر بخش به درس مربوطه لینک دارد.

اندازه‌ها برای ARM Cortex-M (STM32) و Xtensa (ESP32)؛ آدرس‌ها برای STM32F411.

ترفندهای بیت

#define BIT(n)  (1u << (n))
r |=  BIT(n);            /* set    */
r &= ~BIT(n);            /* clear  */
r ^=  BIT(n);            /* toggle */
(r >> n) & 1u             /* test   */
/* multi-bit field: MASK, POS */
r = (r & ~MASK) | (((uint32_t)v << POS) & MASK);
v = (r & MASK) >> POS;
x != 0 && (x & (x - 1)) == 0   /* power of 2? */
sizeof a / sizeof a[0]   /* array length */

همه را با 1u (بی‌علامت) بنویس، نه 1. شیفت به اندازهٔ عرض نوع یا بیشتر (مثلا 1u << 32 روی ۳۲ بیت) رفتار تعریف‌نشده است. ~ روی uint8_t اول به int ارتقا می‌یابد. درس ۳.۱.

volatile و const

نوعکی
volatileرجیستر سخت‌افزار؛ متغیری که ISR عوض می‌کند و حلقهٔ اصلی می‌خواند؛ پرچم بین ISR و main. یعنی: «هر بار واقعا بخوان/بنویس، بهینه نکن»
constداده‌ای که عوض نمی‌شود؛ جدول‌های سراسری const در Flash (.rodata) می‌مانند و RAM نمی‌گیرند
const volatileرجیستر فقط-خواندنی که سخت‌افزار عوض می‌کند (مثل IDR، وضعیت)
staticسراسری فقط در همین فایل، یا متغیر محلی که بین فراخوانی‌ها می‌ماند
externاعلان؛ تعریف در فایل دیگری است

دام‌ها: volatile اتمی بودن نمی‌دهد (x++ روی متغیر ۳۲ بیتی مشترک باید محافظت شود). ثبات را با volatile uint32_t * بخوان، نه uint32_t *. درس ۳.۶.

دستور کار رجیستر: STM32F411 (Nucleo)

#define REG32(addr)   (*(volatile uint32_t *)(addr))
#define RCC_AHB1ENR   REG32(0x40023830u)   /* bit0 GPIOA, bit2 GPIOC */
#define GPIOA_MODER   REG32(0x40020000u)
#define GPIOA_ODR     REG32(0x40020014u)
#define GPIOA_BSRR    REG32(0x40020018u)
#define GPIOC_IDR     REG32(0x40020810u)
#define SYST_CSR      REG32(0xE000E010u)
#define SYST_RVR      REG32(0xE000E014u)

RCC_AHB1ENR |= (1u << 0);                                /* 1) clock GPIOA */
GPIOA_MODER = (GPIOA_MODER & ~(3u << 10)) | (1u << 10);  /* 2) PA5 output (01) */
GPIOA_BSRR = (1u << 5);         /* on  (LD2) */
GPIOA_BSRR = (1u << (5 + 16));  /* off (bits 16..31 = reset) */
GPIOA_ODR ^= (1u << 5);         /* toggle */
((GPIOC_IDR >> 13) & 1u) == 0u /* B1 pressed? active-low; needs GPIOC clock */
SYST_RVR = 16000u - 1u;  SYST_CSR = 7u;  /* SysTick 1 ms @16 MHz: ENABLE|TICKINT|CLKSOURCE */

ترتیب همیشه: کلاک ← حالت پایه ← داده. BSRR برای تغییر بی‌خطر یک پایه بهتر از ODR |= است (خواندن-تغییر-نوشتن ندارد). آدرس‌ها را با RM0383 وارسی کن. baud=115200 با کلاک 16MHz: USART2->BRR = 0x8B (USARTDIV = 16MHz ÷ (16×115200) ≈ 8٫68 → بخش صحیح ۸، کسر ≈ ۱۱/۱۶). درس ۵.۲.

ESP32 (ESP-IDF، فقط قطعه‌کد یادآور): gpio_set_direction(GPIO_NUM_2, GPIO_MODE_OUTPUT); · gpio_set_level(GPIO_NUM_2, 1); · vTaskDelay(pdMS_TO_TICKS(500)); · ESP_LOGI(TAG, "x=%d", x); · ESP_ERROR_CHECK(err); · ساخت: idf.py build flash monitor. درس ۵.۶.
