A. Board Setup BEFORE Any Placement or Routing

P1📺Re-check the schematic at the start of PCB work. Phil caught a swapped USB.D−/D+ net-label pair at this stage.
P2📺Board Setup → Layers: disable everything unused. Keep copper, paste, silkscreen, mask, edge cuts.
P3📺␅Stackup: 2 layers, 1.6 mm nominal — standard and sufficient for a board this simple. Go 4-layer only if needed. Finish: lead-free HASL is cheapest; choose ENIG for very fine pitch or longer shelf life.
P4📺Solder mask settings from the manufacturer's capability page (JLCPCB publishes theirs): mask expansion 0.1mm, min mask web 0.1mm, mask-to-copper clearance 0.1mm.
P5📺␅Enter design-rule constraints before doing anything else. Stay above fab minima — distance from minima = yield.

P6📺␅Predefined sizes so routing only ever uses sanctioned values: signal 0.3mm; power 0.5/1.0mm; fine-pitch escapes 0.15/0.25mm. One via for the whole board: 0.7/0.3mm.
P7📺␅Differential-pair presets: width 0.3/gap 0.3/via-gap 0.5; relaxed to 0.25/0.25 to enter small USB pads.
P8📺Netclass values must agree with constraints — a netclass clearance larger than pad gaps gives “the routing starting point violates DRC”.
P9📺Board Setup → Net Classes → “Import colors from schematic”, then Appearance → Nets → color all items. Colored pads/tracks make routing dramatically clearer.

B. Layout Philosophy

P10📺Layout is the substantial part of PCB design. Place everything before routing anything.
P11📺Real products start from mechanical constraints (board outline, mounting holes, keep-outs) — honor those first.
P12📺Section-based placement: every schematic block has a centerpiece. Place the centerpiece, build its section around it, then stitch sections together.
P13📺Order of criticality: decoupling/bypass caps and crystal first; reset RC and pull-ups last.
P14📺Grid: rough placement on 0.5–1mm, fine placement on 0.25mm. N/Shift+N cycle grids. Hover the component-center cross (not a pad) before pressing M.
P15📺Read the ratsnest while placing — it shows twists, distances and natural flow. Use schematic↔PCB cross-probing.
P16📺Don't scrunch components. Leave room for fan-out, vias, rework, microscope access, probes and test points.
P17📺Re-pin the MCU during layout when it removes crossings/vias; fix the schematic, press F8 to re-import.
P18📺␅All components on one side unless there's a reason not to — single-side assembly is much cheaper.

C. Outline, Origins, Mechanical

P19📺Prefer round-number dimensions and round center-to-center mounting hole spacings. Mounting holes symmetric. Don't fight for minimum size without a reason.
P20📺Outline on Edge.Cuts: lines (Ctrl+Shift+L) + 90° arcs for rounded corners. Note: rounded corners require routed depaneling; V-cut can be cheaper.
P21📺Keep ~0.5mm clearance from board edge for copper, components, and silk.
P22📺Grid origin AND drill/place-file origin at the bottom-left corner of the board (IPC recommendation) → every component has positive X/Y.
P23📺␅Spread the 3 fiducials as far apart as possible (e.g. top-left, bottom-left, bottom-right — deliberately asymmetric).
P24📺Decide consciously whether connector sits flush or overhangs the edge. Courtyards must stay on the board and must not overlap (DRC error).

D. Placement Details

P25📺Decoupling caps: as close as feasible, courtyard-clear. Think about the whole current loop including ground return, not just power-side trace.
P26📺The schematic carries design intent: C6 drawn at pin 7 means C6 is placed at pin 7, even when electrically equivalent pads exist.
P27📺Crystal: close to its pins, away from aggressive signals (USB, fast edges). Load caps placed for desoldering and swapping. When aesthetics and function conflict — function wins.
P28📺Multiple pads on one net are not equivalent: find the pad that actually needs the cap by cross-referencing schematic + datasheet.
P29📺␅ESD protection between connector and circuit, close to the connector. Pi filter close to power entry.
P30📺Routing under connector shells: solder mask is NOT a reliable insulator. Only allowed when connector shell is raised off the board.
P31📺Final silkscreen cleanup happens at the very end — layout will keep changing.
P32📺Use the 3D viewer (Alt+3) constantly — overlapping silk, congestion, connector orientation and rework access all show instantly. “Never use a part without a 3D model.”

E. Zones & Via Pre-placement

P33📺␅2-layer strategy: top = components + signal + power; bottom = one solid GND plane spanning the whole board. Draw the bottom zone first. Repour with B.
P34📺␅Mounting-hole pads: change pad connection from thermal relief to solid — nothing is soldered there, and screws like solid copper.
P35📺Pre-place vias BEFORE routing — vias constrain everything; placing them late means rearranging tracks. Rule: ≥1 GND via adjacent to every GND pad. Never in-pad.
P36📺A via under a small component's belly is sometimes acceptable — but some sensors explicitly forbid copper underneath; check the datasheet.

F. Routing — General Technique

P37📺Route in order of criticality: decoupling-cap links → crystal + ROSC → SWD → NRST → remaining signals → USB differential pair → CC lines → power → ground last.
P38📺Stick to ONE standard signal width (0.3mm) unless impedance or current say otherwise.
P39📺Neck-down/widen-up: leave a pad at its pad width and widen as soon as possible. Neck down only through tight gaps and widen again after. W/Shift+W cycle preset widths while routing.
P40📺Pad entries straight-on at 90°. No acute angles — acid traps are still a real fab issue. Teardrops later smooth these transitions.
P41📺45° bends. Don't hug pads or parallel traces at minimum clearance when space exists — spacing is the #1 cure for crosstalk.
P42📺Keep traces as short as reasonable — long traces are unintentional antennas (EMI). Don't run traces along the board edge.
P43📺Routing under the MCU body is fine when clean; prefer going around when cheap to do so.
P44📺After routing, drag-tune segments (D/drag mode): straighten, give clearance, keep clean entries.

G. Routing — Specific Nets

P45📺Decoupling caps first: shortest and widest possible links to pin and to ground.
P46📺Crystal: short, symmetric; route into the load cap then on into the crystal pin. Put a guard ring of GND stitching vias around the crystal.
P47📺VREF/reference returns: route wide (0.5+) — treat like a power/ground connection.
P48📺␅USB differential pair: press 6 (Route → Differential Pair). Works because of −/+ net-name suffixes. Route together. No length matching needed at FS with runs this short. Avoid vias on the pair.
P49📺CC1/CC2: routed to symmetric pull-downs; keep distance from shield mounting pads.

H. Power Routing

P50📺Route power along the power-flow path: connector → Pi filter (in drawn order: C1 → R1 → C2) → LDO input cap → LDO → output cap → distribution.
P51📺Golden rule: trace → capacitor pad → device power pin. Never trace → pin with the cap hanging off to the side.
P52📺Power widths: match the pad (0.6/0.8mm), neck down only into pads. High-impedance pins on the same net can use 0.3mm.
P53📺Layer changes: press V while routing. Bottom-layer jumps must be few and short, and never under critical signals. Repour (B) after every change.

I. Top Pour, Stitching, Island Hygiene

P54📺␅When power/signals are done, extend GND zone to both layers, repour — it completes most ground connections automatically.
P55📺Nudge pre-placed vias out of thermal-relief zones, or shrink the relief gap so vias land in solid copper.
P56📺Pads the pour can't legally reach: finish with short manual GND tracks.
P57📺Thermal relief vs solid: reliefs exist for solder-thermal balance; where thermal mass is small, switch pad to solid (pad properties → connections).
P58📺Island & antenna hygiene: a lone via feeding a tiny copper islet = a little high-frequency antenna → delete it or join the islet properly. Floating pour necks → carve them off with rule areas.
P59📺␅Via stitching: tie top and bottom GND pours together everywhere. Spacing: λ/10–λ/20 of highest frequency content. “Vias are essentially free — but don't turn the board into Swiss cheese.”

J. Teardrops

P60📺␅Teardrops: widen the trace into the pad — best at wide-pad→narrow-trace boundaries and through-hole pads. Video skips them; published files enable them on PTH + SMD pads + vias.

K. Silkscreen & Board Identification

P61📺No bottom silkscreen if nothing needs it — one fab process step fewer.
P62📺␅Put on the silk: board title/name, revision, designer initials, date code (month/year), company/logo.
P63📺Refs readable and uniform; keep silk off holes and exposed copper (silk-on-pad worsens solderability); pin-1 indicators clear of mask openings.

L. DRC

P64📺Run DRC repeatedly while designing — don't discover 200 errors at the end. Keep “refill all zones before DRC” checked.
P65📺Triage report: solder-mask aperture bridges on fine-pitch parts → set to ignore; clearance mismatches → align the numbers; incomplete thermal reliefs → solid connections or manual traces.
P66📺Awkward footprint clearance: edit the footprint instance — shorten offending pads and shift them so outer edge stays aligned. Save into the board only (library untouched).
P67📺␅Finish at 0 errors AND 0 warnings — every exclusion deliberate, checked and commented.
P68📺Triple-check schematic, pinout and routing before generating manufacturing files.

M. Manufacturing Outputs

P69📺Three deliverables: Gerbers (fab), BOM + CPL/pick-and-place (assembly).
P70📺␅Gerbers → File → Fabrication Outputs → Gerbers → into mfr/ folder: F.Cu, B.Cu, F.Paste only, F.Silkscreen, F.Mask, B.Mask, Edge.Cuts. Options: extended X2 format, use drill/place file origin.
P71📺␅Drill files: Excellon, PTH and NPTH as separate files, drill/place origin, millimeters, decimal format.
P72📺␅Zip Gerbers + drills into one archive — that's the upload.
P73📺␅CPL: Fabrication Outputs → Component Placement File, CSV, mm — then adapt header to exactly what JLCPCB wants: Designator, Value, Footprint, Mid X, Mid Y, Rotation, Layer.
P74📺␅BOM: export from Schematic → Edit Symbol Fields. Check the BOM line-by-line by hand — human error is real.

N. Ordering at JLCPCB

P75📺Upload Gerber zip → confirm auto-detected layer count and dimensions → inspect preview AND open the online Gerber viewer.
P76📺Typical: 5 pcs, FR4, 1.6mm, green mask + white silk (fastest/cheapest), lead-free HASL.
P77📺“Confirm production file” (+~$1) — always. You approve the actual production files the fab will use.
P78📺Assembly: economic vs standard PCBA — fine-pitch parts force standard. Top side only. Enable “confirm parts placement.”
P79📺Upload BOM + CPL → go through it row by row — right part, right package, in stock.
P80📺Expect to fix rotations — every ECAD tool and assembler uses a different 0° convention. Select part, tap spacebar for 90° steps. Verify polarity/pin-1 marks.
P81📺Declare usage (research/education, DIY) for customs. Save to cart, ship.
