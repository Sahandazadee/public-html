چکیده مهم‌ترین قوانین — شماتیک (#165)

  1. اول دیتاشیت و ابزار pinmux سازنده — title block قبل از هر چیز پر شود
  2. سیمبل و فوت‌پرینت را خودت بساز — هرگز از اینترنت دانلود نکن
  3. گرید 100mil — نام‌گذاری PERIPHERAL.SIGNAL
  4. هر net یک label — زوج تفاضلی پسوند -/+
  5. هر پین تغذیه یک 470n + یک 10uF بالک — هرگز 10u و 100n هم‌سایز موازی نشوند
  6. یکسان‌سازی BOM: یک مقدار برای همهجا (470n، 5k1، 0R)
  7. VBUS فیلتر پای C–0R–C — ESD مدل USBLC6 — CC1/CC2 هرکدام 5.1k جدا
  8. NRST: pull-up اجباری (5k1) + خازن — هرگز 0R
  9. ROSC: 100k اما 0.1% و ≤25ppm/°C
  10. کریستال: C = 2×(CL − Cstray) — مرجع ST AN2867
  11. پین بلااستفاده = پرچم Q — ERC صفر خطا
  12. mounting hole (متصل به GND) و ۳ فیدوشال

چکیده مهم‌ترین قوانین — PCB (#166)

  1. قبل از هر کاری قوانین سازنده وارد شود
  2. چیدمان بخش اصلی کار است — کامل قبل از routing
  3. origin گرید گوشه پایین-چپ برد (IPC)
  4. پیش‌جانمایی ویاها قبل از routing
  5. عرض‌ها: 0.3 سیگنال / 0.5+ تغذیه / فقط یک سایز ویا 0.7/0.3
  6. تغذیه همیشه trace ← pad خازن ← پین IC
  7. GND فقط با دو pour (هر دو لایه) + stitching فراوان
  8. DRC حین کار و در پایان: صفر خطا و صفر warning
  9. خروجی‌ها: Gerber (X2) + درل PTH/NPTH جدا + BOM + CPL
  10. سفارش JLC: Confirm production file + Confirm parts placement + اصلاح rotation
