چکیده مهم‌ترین قوانین — شماتیک (#165)

  1. اول دیتاشیت و ابزار pinmux سازنده (SysConfig)، بعد رسم شماتیک — title block قبل از هر چیز پر شود
  2. سیمبل و فوت‌پرینت را خودت بساز — هرگز از اینترنت دانلود نکن؛ کتابخانه شخصی با LCSC/MPN/لینک دیتاشیت یک‌بار بساز و همیشه استفاده کن — فوت‌پرینت حتماً با بخش مکانیکی دیتاشیت تطبیق داده شود
  3. گرید 100mil در شماتیک — هرگز تغییر نکند؛ نام‌گذاری 5k1 / 470n / +3V3 (بدون نقطه)
  4. هر net یک label با ساختار PERIPHERAL.SIGNAL؛ زوج تفاضلی حتماً پسوند -/+ (شرط شناسایی در KiCad)
  5. هر پین تغذیه یک خازن 470n + یک 10uF بالک (0805 به‌خاطر derating) — هرگز 10u و 100n هم‌سایز موازی نشوند (تشدید PDN)
  6. یکسان‌سازی BOM: یک مقدار خازن/مقاومت برای همه‌جا وقتی مقدار بحرانی نیست (470n، 5k1، 0R)
  7. VBUS از فیلتر پای جای‌گذار C–0R–C عبور کند — ESD مدل USBLC6 چسبیده به کانکتور — CC1/CC2 هرکدام 5.1k جدا — شیلد به GND
  8. NRST: pull-up اجباری (5k1) + خازن — هرگز 0R (دیباگر باید بتواند reset بکشد)
  9. ROSC: 100k اما حتماً 0.1% و ≤25ppm/°C — مقاومت معمولی قبول نیست
  10. کریستال: C = 2×(CL − Cstray) با Cstray=3تا5pF — مرجع ST AN2867
  11. پین بلااستفاده = پرچم Q — ERC صفر خطا با PWR_FLAG روی منابع واقعی تغذیه
  12. mounting hole (متصل به GND) و ۳ فیدوشال در خود شماتیک

چکیده مهم‌ترین قوانین — PCB (#166)

  1. قبل از هر کاری قوانین سازنده وارد شود و از حداقل‌های سازنده فاصله بگیر (yield)
  2. چیدمان بخش اصلی کار است — کامل قبل از routing؛ به ترتیب بحرانی: دیکوپلینگ/کریستال اول، pull-up‌ها آخر
  3. شماتیک = design intent: خازنی که کنار پین 7 رسم شده همان‌جا قرار می‌گیرد
  4. origin گرید و drill/place گوشه پایین-چپ برد (IPC)؛ ابعاد عدد رُند
  5. پیش‌جانمایی ویاها قبل از routing — حداقل یک ویای GND کنار هر pad زمین (نه داخل pad)
  6. عرض‌ها: 0.3 سیگنال / 0.5+ تغذیه / فقط یک سایز ویا 0.7/0.3 — خروج از pad با ۹۰ درجه (acid trap واقعی است)
  7. تغذیه همیشه trace ← pad خازن ← پین IC — هرگز مستقیم به پین با خازن آویزان
  8. GND فقط با دو pour (هر دو لایه) + stitching فراوان؛ جزیره‌ها حذف شوند
  9. زوج USB با کلید 6 (diff pair)؛ در FS کوتاه نگه‌دار
  10. DRC حین کار و در پایان: صفر خطا و صفر warning
  11. خروجی‌ها: Gerber (X2) + درل PTH/NPTH جدا + BOM با LCSC + CPL با header دقیق JLC
  12. سفارش JLC: گزینه Confirm production file + Confirm parts placement + اصلاح rotation
