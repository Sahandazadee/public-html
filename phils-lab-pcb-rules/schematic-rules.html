A. Tools & Part Selection

S1📺Choose the MCU from the vendor's product catalog by what the project needs: peripherals, max core clock, flash/RAM size, price.
S2📺The datasheet drives everything — download it from the manufacturer's page and keep it open through the whole design. Also install the vendor IDE (Code Composer Studio, free).
S3📺Don't copy tutorials one-to-one. Apply the method to your own design.

B. Project Setup & Title Block

S4📺✅File → New Project with a sensible name; keep the same name across schematic, PCB and outputs.
S5📺✅Fill in the title block before anything else (Page Settings): title, issue date, revision (letters: Rev A, B…), company/your name. Revision letter appears in every manufacturing filename.
S6✅A simple design fits a single A4 sheet; hierarchical sheets only when complexity demands.

C. Symbols & Footprints — Library Discipline

S7📺Create your own schematic symbols and footprints — a core hardware-design skill. Never download from random internet sources. Build your own populated libraries once and reuse forever.
S8📺Libraries can be project-local or global — choose deliberately.
S9📺Symbol name = the full manufacturer part number. Reference designators: U for ICs, D for diodes, X for crystals (not Y).
S10📺For high-pin-count parts use the pin table (top toolbar) to enter all pins quickly.
S11📺Pin names/numbers come from the datasheet — read the column of your exact package. Electrical types: bidirectional for IO, power input for VDD/VSS.
S12📺Check pin-attributes table: standard vs high drive, 5V-tolerant, open-drain, IO structure.
S13📺Symbol arrangement: positive power pointing up, GND down, IO on left/right. Designator top-left, part name top-right.
S14📺Grid discipline: 100 mil grid for symbols and schematics — never deviate. Pin length 100 mil. N cycles the grid. Schematic units stay in mils.
S15📺Verify every footprint against the datasheet mechanical section. “LQFP-48” is not universal across manufacturers — compare the recommended land pattern.
S16📺✅Minimum fields per symbol: datasheet link, description, manufacturer, MPN, two distributor links (Mouser + Digi-Key), LCSC part number for JLCPCB. Keep as hidden fields.

D. Schematic Organization & Net Labeling

S17📺✅Organize in functional blocks with bold text titles (T key, enlarged text): USB-C, MCU, SWD, etc.
S18📺Label every single net. Short, concise names instead of auto-generated Net-(U1-PA21).
S19📺✅Structured naming PERIPHERAL.SIGNAL (UART0.TX, I2C0.SDA…). Differential pairs must share the base name and end in − / + (USB.D−, USB.D+) — required for KiCad diff-pair routing recognition.
S20📺Value notation: +3V3 not 3.3V, 5k1 not 5.1k, 10u not 10uF, 0R not 0 — dots get lost on schematics.
S21📺GND symbols always point down; hide the value text where redundant.
S22📺✅Power symbols via P; one named rail per conversion stage (+VUSB → +5V → +3V3) so the power chain reads clearly.
S23📺Keep drawing clean; for jumps across the sheet use global labels (Ctrl+L) with direction shape plus a text note.
S24📺✅No-connect flag (Q) on every unused pin — tells ERC these were checked deliberately.
S25📺Crossed connections (TX→RX, RTS→CTS) are a classic mistake — triple-check them. Consider 0R series resistors on TX/RX as swap insurance.

E. USB-C Input

S26📺Use a generic 16-pin USB 2.0 type-C receptacle symbol. Edit the symbol instance (not the library) to rearrange pins for cleaner drawing.
S27📺✅VBUS is nominally 5V but ranges 4.5–5.5V → use a dedicated +VUSB power flag rather than “+5V” at the connector.
S28📺✅CC1 and CC2 each need their own 5.1 kΩ pull-down — they cannot share one resistor. Advertises basic USB-C sink (~1.5A at 5V).
S29📺✅The receptacle has two of every pin (reversible plug). For USB FS just tie D+/D+ and D−/D− together directly.
S30📺Every connection to the external world gets ESD protection, placed right at the connector: USBLC6-2SC6 (SOT-23-6) protecting VBUS and D±.
S31📺✅Tie the connector SHIELD to GND.
S32📺✅Place a placeholder Pi filter on VBUS: C — 0R — C. Adding an unplanned filter later means a board respin; depopulating a placeholder is trivial.

F. 3V3 Regulation

S33📺Regulator choice: LDO = simple/cheap; switcher = efficient but more parts. For a simple board: LDO.
S34📺✅SPX3819 (SOT-23-5): up to 500mA, low noise. Check datasheet capacitance/stability requirements (≥2.2µF aluminum or 1µF tantalum minimum); MLCCs are fine if ESR is low.
S35📺✅EN pin tied straight to the input rail (allowed range 0V–VIN).
S36📺BP (bypass) pin: 10–100 nF lowers output voltage noise — useful for analog rails.

G. Decoupling Strategy & BOM Consolidation

S37📺✅From the datasheet: VCORE = 1.35V internally generated but needs its own external 470nF. Never omit datasheet-mandated caps.
S38📺Do NOT parallel a 10µF and a 0.1µF in similar package sizes (0603/0805) — it creates anti-resonances in the PDN. One 10µF placed close to VDD/VSS pins is better.
S39📺✅One decoupling capacitor per power pin, placed in the schematic next to that pin.
S40📺BOM consolidation: reuse the same handful of values everywhere (470n, 5k1, 0R) when the exact value is non-critical. Fewer BOM lines, fewer reels, cheaper assembly.
S41📺10µF in 0805, not smaller: MLCCs lose capacitance under DC bias (derating). Voltage rating ≥2× the rail. Dielectric X5R/X7R.
S42📺✅Prefer JLCPCB “basic” parts for passives — already loaded on pick-and-place reels, no extended-part loading fee.

H. MCU Support Circuitry

S43📺✅NRST: pull-up to VDD is required for the device to start. Value: order of tens of kΩ; 5k1 chosen to reuse CC value. Plus a small cap to GND (470n). Never a 0R — the debugger must be able to pull NRST low.
S44📺✅ROSC: 100kΩ to GND but must be 0.1% tolerance, ≤25 ppm/°C part. A jellybean 100k will not do. Filter distributor search by tolerance + tempco + in-stock.
S45📺✅VREF+/VREF−: decoupling cap between VREF+ and VREF− required (470n). VREF− goes to GND through a 0R link so it can be opened later.

I. Crystal

S46📺Internal oscillator is fine for casual use, but UART/USB and precise timing want an external crystal.
S47📺✅Package: Crystal_GND24 (3225 = 3.2×2.5 mm) — pins 1/3 are the crystal, pins 2/4 are case shield → tie to GND. Designator X1, value = frequency (8MHz).
S48📺Load capacitor calculation: C_ext = 2 × (CL − C_stray), with C_stray estimated 3–5 pF. Reference document: ST AN2867.
S49📺Check crystal's tolerance and frequency-stability ppm against the interface requirements.
S50📺A series resistor on the drive pin only needed if the MCU overdrives the crystal. AN2867 shows the drive-level calculation.
S51📺Some MCUs need an external 1 MΩ parallel resistor across HFXIN/HFXOUT — verify in the datasheet. Never assume.

J. USB-UART Bridge

S52📺FTDI FT232: well known but pricey (~$6). CH340E: ~$0.4–0.65, MSOP-10, dead simple.
S53📺✅CH340E V3 pin rule: running VCC = 3.3V → tie V3 to VCC; running VCC = 5V → V3 is a regulator output, connect only a decoupling cap.
S54📺✅TX↔RX and RTS↔CTS cross between bridge and MCU. TNOW can drive an indicator LED.

K. Pin Planning

S55📺Preferred: the vendor's graphical pinmux (TI SysConfig in Code Composer Studio) — create project for the exact device, switch to correct package, add peripherals, tool shows legal pin choices.
S56📺Re-assign MCU pins whenever it makes the PCB easier, even mid-layout. Fix schematic and re-import (F8).

L. Adding a Peripheral

S57📺Before committing: check stock at LCSC/JLCPCB, supply ranges, and assembly class — fine-pitch LGA forces “standard” assembly instead of cheaper “economic”.
S58📺Find from the datasheet which pin actually needs the decoupling cap. The cap goes next to the right pin.
S59📺I2C pull-ups to logic rail — 5k1 fine for this slow bus at 3.3V. Check whether interrupt outputs are push-pull or open-drain — pull-ups only for open-drain.

M. Annotation, Net Classes, ERC

S60📺Re-annotate in reading order: left→right, top→bottom. Never duplicate designators (ERC catches it).
S61📺✅Define net classes with colors in the schematic (Schematic Setup → Net Classes), assign by wildcard patterns (/USB*). Colors are imported into the PCB editor.
S62📺␅Run ERC and finish at zero errors: “input power pin not driven” → place PWR_FLAG on true power origins. Legitimate conflicts → exclude with a comment.
S63📺Re-open the footprint assignment tool as a final pass — every symbol must have the correct footprint.

N. Mounting Holes & Fiducials

S64📺␅Add mounting-hole-with-pad symbols tied to GND. Rename H → MH1…; put size in value. M2 or M3; auto-excluded from BOM.
S65📺␅Add fiducials as symbols: 1 mm copper dot, 2 mm mask opening. Minimum 3 per assembled side.
S66📺Tag-Connect TC2030 (SWD): footprint-only, zero BOM cost. Connect VCC, GND, SWDIO, SWCLK + NRST.
S67📺Triple-check the schematic before moving to layout.
