📐 فاز ۱ — طراحی شماتیک

قبل از کشیدن هر خطی، ابتدا ساختار درست را بنا کن

1
ایجاد پروژه و Title Block
اولین قدم — قبل از هر خطی
⚠️ گرید را همیشه روی 100 mil نگه دار. هرگز تغییر نده.
  • File → New Project — نام معنادار انتخاب کن
  • Schematic Editor → File → Page Settings
  • پر کن: Title، Date، Rev (A)، Company/Author
  • هرگز Rev را خالی نگذار
2
ساختن کتابخانه شخصی — Symbol و Footprint
یک‌بار بساز، همیشه استفاده کن
⛔ هرگز Symbol یا Footprint را از سایت‌های تصادفی دانلود نکن.
  • Symbol Editor → New Library → New Symbol
  • نام = شماره کامل قطعه
  • فیلدهای اجباری: Datasheet، MPN، Manufacturer، LCSC
  • فوت‌پرینت را با بخش مکانیکی datasheet تطبیق ده
3
نام‌گذاری Net‌ها
ساختار PERIPHERAL.SIGNAL
  • هر net یک label داشته باشد
  • ساختار: PERIPHERAL.SIGNAL — مثال: UART0.TX
  • زوج تفاضلی: USB.D- و USB.D+

4
مدار ورودی USB-C
CC pull-down، ESD، Pi filter
  • VBUS → net +VUSB (نه +5V)
  • CC1 و CC2 هرکدام 5.1kΩ جداگانه به GND
  • D+ و D- هر طرف به هم وصل
  • شیلد → GND
  • ESD: USBLC6-2SC6 کنار کانکتور
  • Pi filter: C — 0R — C روی VBUS
5
رگولاتور ۳.۳ ولت (LDO)
SPX3819 — خازن‌ها — EN پین
  • SPX3819 (SOT-23-5): تا 500mA، نویز کم
  • ورودی: خازن 10uF (0805) — خروجی: خازن 10uF (0805)
  • پین EN → مستقیم به ورودی
  • Net خروجی: +3V3
6
دیکوپلینگ و BOM Consolidation
یک خازن به ازای هر پین تغذیه
  • یک 470n (0603) به ازای هر پین VDD/VCC
  • یک 10u (0805) bulk — یکی برای کل IC
  • ⚠️ هرگز 10uF و 100nF هم‌سایز موازی نکن — تشدید PDN
  • 10uF حتماً در 0805
7
مدارهای پشتیبان MCU
NRST — ROSC — VREF — USB-UART
  • NRST: pull-up 5k1 + خازن 470n — هرگز 0R
  • ROSC: 100k اما 0.1% و ≤25ppm/°C
  • VREF-: از طریق 0R به GND
  • TX MCU → RX Bridge و RX MCU → TX Bridge — متقاطع
8
کریستال
محاسبه خازن — Crystal_GND24
فرمول: C_ext = 2 × (CL − C_stray) — C_stray ≈ 3–5pF
مرجع: ST AN2867
  • Crystal_GND24 (3225: 3.2×2.5mm)
  • پین‌های 2 و 4 → GND
  • بعضی MCUها مقاومت 1MΩ موازی می‌خواهند — از datasheet بررسی کن

ERC و تأیید نهایی شماتیک
صفر خطا — Mounting holes — Fiducial — PWR_FLAG
  • PWR_FLAG روی هر منبع واقعی تغذیه
  • حداقل 3 mounting hole با net GND
  • حداقل 3 fiducial: 1mm copper / 2mm mask
  • تا صفر خطا و صفر warning ادامه بده

Outline برد و Origin
ابعاد رُند — گوشه پایین-چپ — IPC
  • Outline روی لایه Edge.Cuts
  • Place → Grid Origin → گوشه پایین-چپ
  • Place → Drill/Place File Origin → همان نقطه
  • 3 fiducial در گوشه‌های نامتقارن
13
چیدمان قطعات (Placement)
ابتدا centerpiece — بعد اطراف
  • MCU → کانکتور USB-C → دیکوپلینگ → LDO → کریستال → ESD
  • ratsnest را بخوان
  • courtyard قطعات overlap نداشته باشند
  • Alt+3 برای 3D view — مدام استفاده کن
14
Zone زمین و پیش‌جانمایی Via
GND plane لایه پشت — via قبل از routing
  • B.Cu: Zone GND با Clearance 0.3mm
  • Mounting hole pad → Connections = Solid
  • Via ها را قبل از routing بگذار — نه بعد
  • حداقل یک via GND کنار هر pad زمین

GND Pour و Via Stitching
هر دو لایه — stitching فراوان — جزیره حذف
  • GND zone را به F.Cu هم گسترش ده — Repour
  • Via stitching — فاصله 5–10mm
  • جزیره مس بدون اتصال = آنتن HF — حذف یا وصل کن
18
Silkscreen، Teardrops و DRC
صفر خطا و صفر warning
  • Edit → Teardrops → Add Teardrops
  • روی برد: نام، Rev A، تاریخ، نام طراح
  • silk روی pad یا مس نباشد
  • تا صفر خطا و صفر warning ادامه بده.
19
خروجی‌های ساخت
Gerber — Drill — BOM — CPL
  • Gerbers: F.Cu، B.Cu، F.Paste، F.Silkscreen، F.Mask، B.Mask، Edge.Cuts
  • PTH و NPTH را جداگانه export کن
  • BOM header: Designator, Quantity, Value, Footprint, LCSC
  • CPL header: Designator, Value, Footprint, Mid X, Mid Y, Rotation, Layer
  • Gerbers + Drill را Zip کن
