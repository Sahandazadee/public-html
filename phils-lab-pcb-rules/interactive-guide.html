ایجاد پروژه و پر کردن Title Block
اولین قدم — قبل از هر خطی

چرا مهم است؟

title block هویت برد است. بدون revision letter، وقتی Rev B می‌سازی نمی‌دانی کدام Gerber برای کدام نسخه است. این یک دقیقه کار، ساعت‌ها سردرگمی آینده را نجات می‌دهد.

مراحل اجرا

  • KiCad را باز کن → File → New Project — نام معنادار انتخاب کن (همین نام روی همه خروجی‌ها می‌ماند)
  • Schematic Editor را باز کن → File → Page Settings
  • این فیلدها را پر کن: Title (نام پروژه)، Date (دکمه فلش جادویی)، Rev (حرف: A)، Company/Author (نامت)
  • هرگز Rev را خالی نگذار — هر بار که تغییر اساسی می‌دهی یک حرف جلو برو (A→B→C)

تنظیمات Grid شماتیک

⚠️ گرید را همیشه روی 100 mil نگه دار. هرگز تغییر نده. در غیراینصورت پین‌ها به سیم‌ها وصل نمی‌شوند و debugging کابوس می‌شود.
  • View → Grid Settings → مطمئن شو 100 mil است
  • کلید N بین گریدها سوئیچ می‌کند

ساختن کتابخانه شخصی — Symbol و Footprint
یک‌بار بساز، همیشه استفاده کن
⛔ هرگز Symbol یا Footprint را از سایت‌های تصادفی اینترنت دانلود نکن. اغلب اشتباه هستند و استاندارد ندارند. این یک اشتباه کلاسیک مبتدیان است.

ساختن Symbol

  • Symbol Editor را باز کن → File → New Library (Project type) → نام‌گذاری کن
  • New Symbol ایجاد کن — نام = شماره کامل قطعه از سازنده (مثل MSPM0G3507SPTR)
  • برای قطعه‌های پر‌پین: از Pin Table استفاده کن (نه قرار دادن دستی هر پین)
  • پین‌ها را از ستون بسته مناسب در datasheet بخوان (مثلاً LQFP-48، نه 64-pin)
  • چیدمان: VDD بالا، GND پایین، IO چپ و راست

ساختن Footprint

  • Footprint Editor → New Library → New Footprint

  • "LQFP-48" بین سازنده‌های مختلف متفاوت است — همیشه از datasheet خودت بگیر
  • بعد از ساختن، Footprint را با تصویر 3D در Footprint Editor تأیید کن

نام‌گذاری Net‌ها و سازماندهی شماتیک
ساختار PERIPHERAL.SIGNAL — قانون تفاضلی

قانون نام‌گذاری

  • هر net حتماً باید label داشته باشد — هیچ net بدون نام نباشد
  • ساختار: PERIPHERAL.SIGNAL مثل UART0.TX، I2C0.SDA، SPI0.MISO
  • زوج‌های تفاضلی: USB.D- و USB.D+ — این پسوند شرط شناسایی KiCad برای diff-pair routing است

سازماندهی بصری

  • بلوک‌های عملکردی با عنوان굵 (کلید T) مشخص کن: USB-C، MCU، SWD، LDO
  • GND همیشه پایین، VDD همیشه بالا
  • از global label (Ctrl+L) برای اتصال‌های سراسری استفاده کن
4
مدار ورودی USB-C
CC pull-down، ESD، Pi filter

قوانین USB-C که نباید فراموش کنی

  • از سیمبل USB 2.0 Type-C 16-pin استفاده کن
  • VBUS یک net جداگانه بنام +VUSB بگیر (نه +5V — چون 4.5 تا 5.5 ولت است)
  • CC1 و CC2 هرکدام مقاومت 5.1kΩ جداگانه به GND نیاز دارند — یک مقاومت مشترک نمی‌شود
  • D+ و D- هر طرف را به هم وصل کن (دو پین هر جفت) — برای USB FS مستقیم
  • شیلد کانکتور → مستقیم به GND

حفاظت ESD — اجباری

هر اتصال به دنیای خارج باید ESD داشته باشد. USBLC6-2SC6 (SOT-23-6) محافظت VBUS و D± را فراهم می‌کند. قیمت: چند سنت. هزینه بدون آن: سوختن IC.
  • USBLC6-2SC6 را کنار کانکتور قرار بده (نه وسط مدار)
  • داخل این IC پین‌های 1↔6 و 3↔4 به هم وصل هستند — نیازی به routing نیست

Pi Filter روی VBUS — placeholder اجباری

اضافه کردن فیلتر بعد از ساخت برد = respin. حذف placeholder = آسان. همیشه C — 0R — C قرار بده حتی اگر فعلاً populate نکنی.
  • ترتیب: +VUSB → C1 → 0R (R_filter) → C2 → +5V
  • net بعد از فیلتر +5V نام بگیرد
5
رگولاتور ۳.۳ ولت (LDO)
SPX3819 — خازن‌ها — EN پین

چه رگولاتوری انتخاب کنیم؟

  • LDO = ساده، ارزان، مناسب اکثر پروژه‌ها
  • SPX3819 (SOT-23-5): تا 500mA، نویز کم، ورودی تا 16V — انتخاب کلاسیک

مدار اطراف LDO

  • ورودی: خازن 10uF (0805) به GND — از datasheet: حداقل 2.2uF ceramic
  • خروجی: خازن 10uF (0805) به GND
  • پین EN را مستقیم به ورودی وصل کن (LDO همیشه روشن باشد)
  • پین BP: اختیاری — 470n به GND برای کاهش نویز (اگر analog دارید مفید است)
💡 Net بعد از LDO را +3V3 بنام (نه 3.3V — نقطه گم می‌شود).
6
دیکوپلینگ و BOM Consolidation
یک خازن به ازای هر پین تغذیه — قانون ضدتشدید

قانون طلایی دیکوپلینگ

هر پین تغذیه یک خازن دیکوپلینگ کنارش می‌خواهد. این خازن نویز آن پین را جذب می‌کند. بدون آن، نویز یک IC به IC دیگر می‌رود.
  • یک 470n (0603) به ازای هر پین VDD/VCC کنار همان پین در شماتیک
  • یک 10u (0805) bulk — یکی برای کل IC (نه یکی به ازای هر پین)
  • ⚠️ هرگز 10uF و 100nF هم‌سایز (0603/0805) موازی نکن — تشدید PDN ایجاد می‌شود
  • 10uF حتماً در 0805 — خازن‌های کوچک‌تر زیر ولتاژ DC ظرفیت از دست می‌دهند

BOM Consolidation — کاهش تنوع قطعات

مقدار استانداردکجا استفاده می‌شود
470nهمه دیکوپلینگ‌ها، VREF، NRST cap
5k1CC1، CC2، NRST pull-up، I2C pull-up

💡 فقط از JLCPCB Basic parts برای passives استفاده کن — هیچ extended-part fee ندارند.
7
مدارهای پشتیبان MCU
NRST — ROSC — VREF — USB-UART Bridge

NRST — پین ریست

  • NRST باید pull-up داشته باشد (5k1 به VDD) — بدون آن MCU شروع نمی‌کند
  • یک خازن 470n به GND اضافه کن — زمان بالا آمدن ولتاژ را کنترل می‌کند
  • هرگز 0R نگذار — debugger باید بتواند NRST را پایین بکشد
  • NRST را به connector دیباگ (SWD/JTAG) هم وصل کن

ROSC — اسیلاتور داخلی

⚠️ 100kΩ معمولی کافی نیست. حتماً 0.1% tolerance و ≤25ppm/°C باید باشد. این مقاومت دقت اسیلاتور داخلی را تنظیم می‌کند.

VREF (اگر analog دارید)

  • یک 470n بین VREF+ و VREF-
  • VREF- را از طریق یک 0R به GND وصل کن (تا بعداً قابل جدا کردن باشد)

USB-UART Bridge — CH340E

  • CH340E (MSOP-10): حدود $0.4 — جایگزین ارزان FT232
  • اگر VCC = 3.3V: پین V3 را به VCC وصل کن
  • اگر VCC = 5V: پین V3 فقط یک خازن 470n به GND
  • TX MCU → RX Bridge و RX MCU → TX Bridge — اتصالات متقاطع هستند
8
کریستال
محاسبه خازن — Crystal_GND24 — گرید 100mil

کِی به کریستال نیاز داریم؟

  • اسیلاتور داخلی برای کارهای ساده کافی است
  • USB، UART دقیق، یا RTC → حتماً به کریستال خارجی نیاز داری

محاسبه خازن‌های Load

فرمول: C_ext = 2 × (CL − C_stray)
مثال: CL = 12pF، C_stray ≈ 4pF → C_ext = 2 × (12 − 4) = 16pF → از 15pF استفاده کن
مرجع: ST AN2867
  • بسته Crystal_GND24 انتخاب کن (3225: 3.2×2.5mm)
  • پین‌های 2 و 4 (شیلد) را به GND وصل کن
  • Designator = X1، Value = فرکانس (8MHz)
  • تلرانس و stability را با نیاز interface چک کن
  • بعضی MCU ها مقاومت 1MΩ موازی می‌خواهند — حتماً از datasheet بررسی کن

10
ERC و تأیید نهایی شماتیک
صفر خطا — Mounting holes — Fiducial — PWR_FLAG

چک‌لیست قبل از ERC

  • همه پین‌های بلااستفاده پرچم Q دارند
  • PWR_FLAG روی هر منبع واقعی تغذیه (GND اصلی، VBUS، خروجی LDO)
  • PWR_FLAG را از connectorها استفاده کن — بدون آن ERC خطای "power pin not driven" می‌دهد

Mounting Holes و Fiducials

  • حداقل 3 mounting hole با net GND اضافه کن (M2 یا M3)
  • حداقل 3 fiducial: 1mm copper / 2mm mask opening — از KiCad library بگیر
  • اینها در BOM نباشند (گزینه "Exclude from BOM" را چک کن)

اجرای ERC

  • Inspect → Electrical Rules Checker → Run ERC
  • هر خطا را بررسی کن: اگر واقعی است، رفع کن؛ اگر عمداً است، با comment exclude کن
  • تا رسیدن به صفر خطا و صفر warning ادامه بده
  • تأیید نهایی: Footprint Assignment Tool — همه سیمبل‌ها footprint دارند

تنظیمات ابتدایی PCB — Board Setup
اول constraints — بعد هر چیز دیگری
⚠️ این تنظیمات را قبل از هر چیز انجام بده. برد بدون constraint درست، غیرقابل ساخت است.

Board Setup → Physical Stackup

  • 2 لایه، FR4، 1.6mm — استاندارد و کافی برای اکثر پروژه‌ها
  • Copper finish: HASL (ارزان) یا ENIG (برای fine-pitch یا shelf life بلند)

Pre-defined Sizes — اجباری

  • Track widths: 0.15, 0.25, 0.3, 0.5, 1.0 mm

  • Diff pair: 0.25 width / 0.25 gap

  • Appearance → Nets → Net color display: همه آیتم‌ها رنگی باشند
12
Outline برد و Origin
ابعاد رُند — گوشه پایین-چپ — IPC
  • ابتدا همه قطعات را تقریباً بچین — بعد outline را رسم کن
  • ابعاد عدد رُند انتخاب کن (مثل 45×20mm، نه 43.7×19.3mm)
  • Outline روی لایه Edge.Cuts: Ctrl+Shift+L برای خط
  • گوشه‌های گرد: arc با مرکز روی mounting hole

Origin گذاری (بسیار مهم)

طبق IPC، origin باید گوشه پایین-چپ برد باشد. این کار باعث می‌شود همه X و Y مثبت باشند و pick-and-place machine سردرگم نشود.
  • Place → Grid Origin → کلیک روی گوشه پایین-چپ Edge.Cuts
  • Place → Drill/Place File Origin → همان نقطه
  • فاصله مس از لبه: حداقل 0.4–0.5mm

Fiducials در PCB

  • 3 fiducial در گوشه‌های نامتقارن (مثلاً بالاچپ، پایین‌چپ، پایین‌راست)
  • reference آنها را در silk مخفی کن
13
چیدمان قطعات (Placement)
ابتدا centerpiece — بعد اطراف — ratsnest را بخوان

ترتیب چیدمان (به ترتیب بحرانی بودن)

  • ۱. MCU را وسط یا کنار برد بگذار — همه چیز اطرافش می‌چرخد
  • ۲. کانکتور USB-C را روی لبه برد
  • ۳. خازن‌های دیکوپلینگ — کنار همان پین که در شماتیک هستند
  • ۴. LDO با خازن‌هایش — نزدیک کانکتور
  • ۵. کریستال — نزدیک MCU، دور از USB و سیگنال‌های سریع
  • ۶. ESD — بین کانکتور و مدار
  • ۷. CH340E — نزدیک MCU، TX/RX از یک سمت
  • ۸. SWD connector — کنار MCU

نکات طلایی چیدمان

  • ratsnest را بخوان — اگر خطوط پیچیده است، قطعه را بچرخان یا جابجا کن
  • حریم (courtyard) قطعات نباید با هم overlap داشته باشند
  • فضا بگذار: برای fan-out، via، rework، probe
  • Alt+3 برای 3D view — مدام استفاده کن
  • گرید: جابجایی درشت 1mm، تنظیم دقیق 0.25mm
  • M را روی مرکز قطعه بزن (نه روی pad) — Hover کن تا cross center دیدی

قانون شماتیک = intent چیدمان

اگر در شماتیک C6 کنار پین 7 رسم کردی، در PCB هم باید کنار پین 7 باشد — حتی اگر electrically معادل باشد. «اصل است که از ابتدا درست انجام دهی.»
14
Zone زمین و پیش‌جانمایی Via
GND plane لایه پشت — via قبل از routing

استراتژی 2-لایه

لایه بالا: قطعات + سیگنال + تغذیه
لایه پایین: یک صفحه GND کامل — بهترین تصمیم در دو لایه

ایجاد GND Zone

  • B.Cu را انتخاب کن → Place → Add Rule Area (Ctrl+Shift+Z)
  • Net = GND، نام بده (مثل "GND_BOTTOM")
  • Clearance: 0.3mm، Min width: 0.2mm
  • Thermal relief: gap 0.3mm، spoke 0.3mm
  • کل برد را دور بکش — pour خودش clip می‌شود
  • کلید B برای repour

تنظیم Pad Mounting Holes

  • هر mounting hole pad → Pad Properties → Connections = Solid (نه thermal relief)
  • چیزی به mounting hole لحیم نمی‌شود — مستقیم بهتر است

پیش‌جانمایی Via — قبل از هر routing

Via ها را قبل از routing بگذار. Via بعداً همه چیز را محدود می‌کند — اگر بعداً بگذاری باید track ها را جابجا کنی.
  • حداقل یک via GND کنار هر pad زمین (نه داخل pad — via-in-pad فرایند خاص می‌خواهد)
  • Via size: 0.7mm diameter / 0.3mm drill
  • کنار کریستال یک حلقه via GND برای shield
15
Routing سیگنال‌ها
ترتیب بحرانی — 0.3mm — 45° — USB diff pair

ترتیب routing

  • ۱. دیکوپلینگ cap ها — کوتاه‌ترین و پهن‌ترین ممکن
  • ۲. کریستال — کوتاه، متقارن
  • ۳. ROSC مقاومت — کوتاه به GND
  • ۴. SWD (SWDIO، SWDCLK، NRST)
  • ۵. I2C، UART، سیگنال‌های معمولی
  • ۶. USB differential pair
  • ۷. CC1، CC2
  • ۸. تغذیه (+5V، +3V3)
  • ۹. GND — آخر از طریق zone

قوانین routing

  • ضخامت استاندارد سیگنال: 0.3mm (همان عرض pad LQFP)
  • فقط 45° bend — هرگز 90° تیز
  • هرگز زاویه تیز (acute) نزن — acid trap واقعی است و سازنده می‌گوید
  • ورود به pad: مستقیم 90° درجه — از کنار وارد نشو
  • Neck-down فقط در تنگنا، بعد فوری پهن شو

USB Differential Pair — کلید 6

  • اول این که net‌ها USB.D- و USB.D+ نام دارند (شرط اجرا)
  • کلید 6 یا Route → Route Differential Pair
  • هر دو سیم را با هم route کن — نباید از هم جدا شوند
  • در USB Full Speed با route کوتاه: length matching و impedance control لازم نیست
  • از via روی جفت تفاضلی پرهیز کن

Routing تغذیه
trace → خازن → پین IC — قانون طلایی

قانون طلایی تغذیه

⚠️ همیشه: trace → pad خازن → پین IC
هرگز: trace مستقیم به پین با خازن آویزان به کنار
خازن دیکوپلینگ فقط وقتی «سر راه» باشد کار می‌کند.

مسیر تغذیه

  • کانکتور → C1 (Pi filter) → R_filter → C2 → LDO input cap → LDO → LDO output cap → توزیع
  • ترتیب درون Pi filter: pad C1 → pad مشترک → pad R → pad R دیگر → pad C2

عرض trace تغذیه

مسیرعرض
VBUS / +5V اصلی0.8–1.0mm
+3V3 اصلی0.5–0.8mm
پین EN یا impedance بالا0.3mm کافی است

تغییر لایه

  • کلید V حین routing: via می‌گذارد و به لایه مقابل می‌رود
  • لایه پشت باید GND plane بماند — برش‌های لایه پشت کم و کوتاه باشند
  • هرگز برش زیر USB diff pair
  • بعد از هر تغییر: B برای repour

GND Pour و Via Stitching
هر دو لایه — stitching فراوان — جزیره حذف

گسترش GND به لایه بالا

  • Zone Properties لایه B.Cu → F.Cu را هم چک کن
  • Repour با B — اکثر اتصالات GND خودبخود کامل می‌شوند
  • پین‌هایی که pour نمی‌رسد → یک track کوتاه GND دستی بکش

Thermal Relief vs Solid

  • SMD pad کوچک = solid (Pad Properties → Connections → Solid)
  • THT pad = thermal relief (برای لحیم‌کاری دستی راحت‌تر)
  • Mounting hole = solid (چیزی لحیم نمی‌شود)

Via Stitching — اتصال دو لایه GND

via stitching دو صفحه GND (F.Cu و B.Cu) را به هم وصل می‌کند. هرچه بیشتر، inductance کمتر و EMI بهتر. در برد 2 لایه بسیار مهم است.
  • Via ها را در گوشه‌ها، اطراف برد، و بین قطعات بگذار
  • فاصله حدودی: 5–10mm برای برد کم‌فرکانس
  • Via ها ارزان هستند — در تعداد بخل نکن

بهداشت جزیره‌ها

  • جزیره مس بدون اتصال = آنتن HF — حذف یا وصل کن
  • زائده‌های باریک pour را با Rule Area حذف کن

Silkscreen، Teardrops و DRC
صفر خطا و صفر warning — هیچ استثنایی نیست

Teardrops

  • Edit → Teardrops → Add Teardrops برای SMD، PTH، Via
  • باعث می‌شود trace به تدریج وارد pad شود — قابلیت ساخت بهتر

Silkscreen

  • روی برد: نام برد، Rev A، تاریخ، نام طراح
  • silk روی pad یا مس نباشد — لحیم‌پذیری کاهش می‌یابد
  • indicator پین 1 روی همه IC‌ها واضح باشد
  • ref ها خوانا و یکسان باشند — مخفی کردن مجاز است اگر فضا کم است

DRC نهایی

  • Inspect → Design Rules Checker — گزینه "Refill zones before DRC" چک باشد
  • هر خطا را بررسی کن:
  • solder-mask bridge روی fine-pitch (LQFP, MSOP): می‌توان به warning تبدیل کرد
  • clearance mismatch: اعداد constraint و netclass را هماهنگ کن
  • تا صفر خطا و صفر warning ادامه بده. هر exclusion باید comment داشته باشد.

خروجی‌های ساخت
Gerber — Drill — BOM — CPL

Gerber

  • File → Fabrication Outputs → Gerbers → پوشه mfr/
  • لایه‌های اجباری: F.Cu، B.Cu، F.Paste (نه B.Paste اگر یک طرف)، F.Silkscreen، F.Mask، B.Mask، Edge.Cuts
  • Format: Extended Gerber X2، Use drill/place file origin

Drill

  • File → Fabrication Outputs → Drill Files
  • PTH و NPTH را جداگانه export کن
  • Format: Excellon، millimeters، decimal

BOM

  • Schematic → Edit Symbol Fields → Export
  • Header برای JLC: Designator, Quantity, Value, Footprint, LCSC
  • سطر به سطر بررسی کن — خطای انسانی واقعی است

CPL (Component Placement List)

  • File → Fabrication Outputs → Component Placement
  • Header دقیق JLC: Designator, Value, Footprint, Mid X, Mid Y, Rotation, Layer

Zip و ارسال

  • همه فایل‌های Gerber + Drill را Zip کن
  • BOM.csv و CPL.csv را جداگانه نگه دار (برای assembly upload)
