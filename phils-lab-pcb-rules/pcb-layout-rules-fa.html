بخش‌ها

الف. تنظیمات برد ب. فلسفه Layout ج. کانتور و مبدأ د. جزئیات چیدمان ه. Zone‌ها و Via‌ها و. تکنیک Routing ز. نت‌های خاص ح. Routing پاور ط. Pour بالا و stitching ی. Teardrop‌ها ک. Silkscreen ل. DRC م. ساخت ن. سفارش JLCPCB

الف. تنظیمات برد — قبل از هر چیدمان یا Routing

P1📺شماتیک را دوباره بررسی کن در ابتدای کار PCB.
P2📺Board Setup → Layers: همه لایه‌های بلااستفاده را غیرفعال کن. مس، paste، silkscreen، mask، edge cuts را نگه‌دار.
P3📺✅Stackup: ۲ لایه، ۱.۶ میلی‌متر اسمی. پوشش: HASL بدون سرب ارزان‌ترین؛ ENIG برای پیچ ظریف یا عمر طولانی.
P4📺تنظیمات solder mask از صفحه توانایی‌های سازنده: گسترش mask 0.1mm، حداقل عرض mask 0.1mm.
P5📺✅قبل از هر کاری محدودیت‌های طراحی را وارد کن:
محدودیتمقدار ویدیوفایل منتشرشده
حداقل clearance0.152 mm0.15 mm
حداقل عرض track0.152 mm0.15 mm
حداقل قطر via0.6 mm0.6 mm
فاصله مس تا لبه0.5 mm0.4 mm
حداقل through-hole0.3 mm0.3 mm
P6📺✅سایزهای از پیش تعریف‌شده: سیگنال 0.3mm؛ پاور 0.5/1.0mm؛ fine-pitch 0.15/0.25mm. یک via برای کل برد: 0.7/0.3mm.
P7📺✅پیش‌تنظیمات differential-pair: عرض 0.3/گپ 0.3؛ ریلکس به 0.25/0.25 برای ورود به pad‌های USB کوچک.
P8📺مقادیر Netclass باید با محدودیت‌ها مطابقت داشته باشد.
P9📺Board Setup → Net Classes → «رنگ‌ها را از شماتیک وارد کن».

ب. فلسفه Layout

P10📺Layout بخش اصلی طراحی PCB است. همه چیز را قبل از routing بچین.
P11📺محصولات واقعی از محدودیت‌های مکانیکی شروع می‌شوند — اول آن‌ها را رعایت کن.
P12📺چیدمان بر اساس بخش: هر بلوک شماتیک یک قطعه مرکزی دارد. آن را اول قرار بده، بخش را دورش بساز.
P13📺ترتیب اهمیت: خازن‌های دی‌کاپلینگ/bypass و کریستال اول؛ RC ریست و pull-up‌ها آخر.
P14📺گرید: چیدمان تقریبی روی 0.5–1mm، چیدمان دقیق روی 0.25mm. قبل از فشردن M روی علامت مرکز قطعه Hover کن.
P15📺حین چیدمان ratsnest را بخوان.
P16📺قطعات را فشرده نچین. فضا برای fan-out، via، rework، probe بگذار.
P17📺حین layout پین‌های MCU را تغییر بده وقتی crossing/via کم می‌شود؛ شماتیک را درست کن، F8 بزن تا re-import شود.
P18📺✅همه قطعات روی یک طرف مگر دلیل خاصی باشد — اسمبل تک طرفه بسیار ارزان‌تر است.

ج. کانتور، مبدأ، مکانیک

P19📺ابعاد عدد رند و فاصله مرکز به مرکز سوراخ‌های mounting عدد رند ترجیح داده می‌شود.
P20📺کانتور روی Edge.Cuts: خطوط (Ctrl+Shift+L) + قوس ۹۰ درجه برای گوشه‌های گرد.
P21📺~۰.۵ میلی‌متر فاصله از لبه برد برای مس، قطعات و silk.
P22📺مبدأ گرید و مبدأ drill/place-file در گوشه پایین‌چپ برد (IPC).
P23📺✅۳ fiducial را تا جای ممکن از هم دور قرار بده — عمداً غیرمتقارن.
P24📺Courtyard‌ها باید داخل برد باشند و نباید روی هم بروند (خطای DRC).

د. جزئیات چیدمان

P25📺خازن‌های دی‌کاپلینگ: تا جای ممکن نزدیک، courtyard پاک. به کل حلقه جریان شامل مسیر برگشت GND فکر کن.
P26📺شماتیک هدف طراحی را منتقل می‌کند: C6 رسم‌شده روی پین ۷ یعنی C6 روی پین ۷ قرار می‌گیرد.
P27📺کریستال: نزدیک به پین‌هایش، دور از سیگنال‌های تهاجمی (USB، لبه‌های تند). عملکرد مهم‌تر از زیبایی است.
P28📺چند pad روی یک نت معادل نیستند: با ارجاع متقاطع شماتیک + دیتاشیت pad درست را پیدا کن.
P29📺✅حفاظت ESD بین کانکتور و مدار، نزدیک کانکتور.
P30📺Routing زیر شل کانکتور: solder mask عایق قابل اعتمادی نیست.
P31📺تمیزکاری نهایی silkscreen در آخرین مرحله انجام می‌شود.
P32📺مدام از نمای سه‌بعدی (Alt+3) استفاده کن. «هرگز قطعه‌ای بدون مدل سه‌بعدی استفاده نکن.»

ه. Zone‌ها و پیش‌چیدمان Via

P33📺✅استراتژی ۲ لایه: بالا = قطعات + سیگنال + پاور؛ پایین = یک پلن GND کامل. با B repour کن.
P34📺✅pad‌های mounting hole: اتصال را به solid تغییر بده — چیزی لحیم نمی‌شود.
P35📺قبل از routing، via‌ها را از پیش بچین. قانون: ≥۱ via GND مجاور هر pad GND. هرگز داخل pad.
P36📺via زیر شکم قطعه گاهی قابل قبول است — بعضی سنسورها مس زیرشان را ممنوع می‌کنند؛ دیتاشیت را بررسی کن.

و. Routing — تکنیک کلی

P37📺به ترتیب اهمیت Route کن: لینک‌های دی‌کاپلینگ → کریستال + ROSC → SWD → NRST → سیگنال‌ها → جفت دیف USB → CC → پاور → GND.
P38📺روی یک عرض استاندارد سیگنال (0.3mm) بمان مگر impedance یا جریان چیز دیگری بگوید.
P39📺فقط در گپ‌های تنگ باریک کن و دوباره پهن کن. W/Shift+W چرخه سایزهای preset.
P40📺ورودی pad‌ها مستقیم در ۹۰ درجه. بدون زاویه حاد — acid trap مشکل واقعی ساخت است.
P41📺خم ۴۵ درجه. فاصله‌گذاری مهم‌ترین راه مقابله با crosstalk است.
P42📺Trace‌ها را تا جای ممکن کوتاه نگه‌دار — trace‌های بلند آنتن ناخواسته هستند.
P43📺Routing زیر بدنه MCU وقتی تمیز باشد مشکلی ندارد.
P44📺بعد از routing با drag-tune سگمنت‌ها (D): صاف کن، clearance بده، ورودی‌های تمیز نگه‌دار.

ز. Routing — نت‌های خاص

P45📺خازن‌های دی‌کاپلینگ اول: کوتاه‌ترین و پهن‌ترین لینک‌های ممکن.
P46📺کریستال: کوتاه، متقارن. یک حلقه guard از via‌های GND stitching دور کریستال.
P47📺برگشت‌های VREF/reference: عریض Route کن (0.5+).
P48📺✅جفت دیفرانسیل USB: ۶ بزن (Route → Differential Pair). در FS نیاز به length matching نیست. از via روی جفت اجتناب کن.
P49📺CC1/CC2: به pull-down‌های متقارن Route می‌شوند.

ح. Routing پاور

P50📺پاور را طبق مسیر جریان پاور Route کن: کانکتور → فیلتر Pi → خازن ورودی LDO → LDO → خازن خروجی → توزیع.
P51📺قانون طلایی: trace → pad خازن → پین پاور دستگاه. هرگز trace → پین با خازن آویزان به کنار.
P52📺عرض‌های پاور: با pad مطابقت بده (0.6/0.8mm).
P53📺تغییر لایه: حین routing V بزن. هرگز زیر سیگنال‌های حساس. بعد از هر تغییر Repour (B) کن.

ط. Pour بالا، Stitching، بهداشت جزیره

P54📺✅Zone GND را به هر دو لایه گسترش بده، repour کن.
P55📺via‌های از پیش چیده‌شده را از zone‌های thermal-relief دور کن.
P56📺pad‌هایی که pour نمی‌رسد: با track کوتاه دستی GND تکمیل کن.
P57📺thermal relief در مقابل solid: relief برای THT؛ solid جایی که جرم حرارتی کم است.
P58📺بهداشت جزیره و آنتن: یک via تنها که یک جزیره مس کوچک تغذیه می‌کند = آنتن فرکانس بالا → حذف یا درست وصل کن.
P59📺✅Via stitching: پلن‌های GND بالا و پایین را همه جا به هم وصل کن. «via‌ها اساساً رایگان هستند.»

ی. Teardrop‌ها

P60📺✅Teardrop‌ها: trace را به داخل pad پهن می‌کنند. ویدیو آن‌ها را رد می‌کند؛ فایل‌های منتشرشده آن‌ها را روی PTH + SMD pad + via فعال می‌کنند.

ک. Silkscreen و شناسایی برد

P61📺اگر نیازی نیست silkscreen زیرین قرار نده.
P62📺✅روی silk بگذار: عنوان/نام برد، ریویژن، حروف اول طراح، کد تاریخ، شرکت/لوگو.
P63📺Silk را دور از سوراخ‌ها و مس برهنه نگه‌دار (silk روی pad لحیم‌کاری را بدتر می‌کند).

ل. DRC

P64📺حین طراحی مکرراً DRC اجرا کن.
P65📺گزارش را دسته‌بندی کن: پل solder mask روی fine-pitch → ignore؛ عدم تطابق clearance → اعداد را تنظیم کن.
P66📺clearance فوت‌پرینت دشوار: نمونه فوت‌پرینت را ویرایش کن — فقط در برد ذخیره کن.
P67📺✅با ۰ خطا و ۰ هشدار تمام کن — هر استثناء عمدی و با توضیح.
P68📺قبل از تولید فایل‌های ساخت، شماتیک، pinout و routing را سه بار بررسی کن.

م. خروجی‌های ساخت

P69📺سه تحویلی: Gerber (fab)، BOM + CPL/pick-and-place (اسمبلی).
P70📺✅Gerber → در mfr/: F.Cu، B.Cu، F.Paste، F.Silkscreen، F.Mask، B.Mask، Edge.Cuts. فرمت: X2 پیشرفته، از مبدأ drill/place file استفاده کن.
P71📺✅فایل‌های Drill: Excellon، PTH و NPTH به صورت فایل‌های جداگانه، میلی‌متر، فرمت اعشاری.
P72📺✅Gerber‌ها + drill‌ها را در یک آرشیو Zip کن.
P73📺✅هدر CPL برای JLCPCB: Designator, Value, Footprint, Mid X, Mid Y, Rotation, Layer.
P74📺✅BOM: از Schematic → Edit Symbol Fields خروجی بگیر. خط به خط بررسی کن — خطای انسانی واقعی است.

ن. سفارش در JLCPCB

P75📺Gerber zip آپلود کن → تعداد لایه و ابعاد خودکار تشخیص‌داده‌شده را تأیید کن → پیش‌نمایش و Gerber viewer را بررسی کن.
P76📺معمولی: ۵ عدد، FR4، ۱.۶mm، ماسک سبز + silk سفید، HASL بدون سرب.
P77📺«تأیید فایل تولید» (~۱ دلار اضافه) — همیشه.
P78📺اسمبلی: فقط طرف بالا. «تأیید چیدمان قطعات» را فعال کن.
P79📺BOM + CPL آپلود کن → ردیف به ردیف بررسی کن.
P80📺انتظار تصحیح rotation‌ها را داشته باش — هر نرم‌افزار ECAD و هر مونتاژکار قرارداد ۰ درجه متفاوتی دارد. Spacebar برای گام‌های ۹۰ درجه.
P81📺کاربرد را اعلام کن (تحقیق/آموزش، DIY) برای گمرک. به سبد خرید اضافه کن، ارسال.
